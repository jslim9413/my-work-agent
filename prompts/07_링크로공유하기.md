# 2부 3교시 — 링크로 내 Agent 공유하기 (배포)

목표: 내 PC에서만 돌던 앱을 `https://내이름-agent.streamlit.app` 같은 **링크 하나로 어디서든** 열리게 하기
사용 서비스: GitHub(코드 보관) + Streamlit Community Cloud(무료 실행 서버)

```
내 PC ──git push──▶ GitHub 저장소 ──자동 연결──▶ Streamlit Community Cloud ──링크──▶ 누구나(휴대폰 포함)
                                                    ▲ Secrets: API 키·비밀번호 (코드에 안 넣음)
```

## 꼭 알아야 할 무료 플랜 조건
- 무료. 공개(public) 앱은 개수 제한 없음, 비공개(private) 앱은 계정당 1개
- 12시간 동안 아무도 안 들어오면 잠듦 → 다음 방문자가 "깨우기" 버튼을 누르면 1분 안에 다시 켜짐
- 메모리 약 1GB, 서버는 미국에 있음 → **회사 실제 문서는 올리지 말 것**
- GitHub 에 push 하면 몇 분 안에 자동으로 다시 배포됨

---

## STEP 1. 배포 전 점검 (Claude Code, 10분)
```
이 프로젝트를 Streamlit Community Cloud 에 배포하려고 해. 고치기 전에 먼저 점검만 해서 표로 보여줘.
1. 배포할 앱 파일(my_app.py 또는 streamlit_app.py)이 로컬에서 에러 없이 실행되는지
2. requirements.txt 에 앱이 import 하는 패키지가 빠짐없이 있는지 (pytest 같은 개발용은 빼도 됨)
3. .gitignore 에 .env 와 .streamlit/secrets.toml 이 들어 있는지
4. 코드나 문서 어디에도 API 키(sk-or 로 시작)가 직접 적혀 있지 않은지
5. 파일 경로가 윈도우 전용(C:\ 나 역슬래시)으로 적힌 곳이 없는지 (서버는 리눅스)
문제가 있으면 고칠 방법도 같이 적어줘.
```
✅ 확인: 5개 항목이 모두 OK

## STEP 2. GitHub 에 빈 저장소 만들기 (웹, 5분)
1. github.com 로그인 → 오른쪽 위 **+** → **New repository**
2. Repository name: `my-work-agent` (영문·숫자·하이픈)
3. **Public** 선택 (샘플 데이터만 있으니 공개해도 됨. 비공개는 무료 1개 한도에 주의)
4. README, .gitignore 추가 체크는 **모두 해제** (키트에 이미 있음) → **Create repository**
5. 화면에 보이는 주소 `https://github.com/내아이디/my-work-agent.git` 복사

## STEP 3. 코드 올리기 (Claude Code, 10분)
```
GitHub 에 빈 저장소를 만들었어. 주소는 https://github.com/내아이디/my-work-agent.git 이야.
1. 이 폴더를 git 저장소로 만들고 기본 브랜치를 main 으로 해줘.
2. 커밋하기 전에 올라갈 파일 목록을 보여주고, .env 와 secrets.toml 이 목록에 없는지 확인해줘.
3. 커밋 메시지 "내 업무 Agent 첫 배포" 로 커밋하고 위 주소로 push 해줘.
4. push 할 때 GitHub 로그인 창이 뜨면 내가 처리할게. 끝나면 GitHub 에서 확인할 주소를 알려줘.
```
✅ 확인: GitHub 저장소 페이지에 파일들이 보이고 **.env 는 없음**

> 🔐 Windows(Git Bash)는 첫 push 때 브라우저 로그인 창이 뜹니다. "Sign in with your browser" → 승인.
> Mac 은 `gh auth login` 을 먼저 하거나 GitHub Desktop 앱으로 올리는 방법이 더 쉽습니다.

## STEP 4. Streamlit Community Cloud 에 배포 (웹, 10분)
1. **share.streamlit.io** 접속 → GitHub 계정으로 로그인 → GitHub 연결 권한 승인
2. 오른쪽 위 **Create app** → **Yup, I have an app**
3. 입력
   - Repository: `내아이디/my-work-agent`
   - Branch: `main`
   - Main file path: `my_app.py` (정답 코드로 배포하려면 `streamlit_app.py`)
   - App URL: `내이름-agent` 처럼 원하는 주소 (선택)
4. **Advanced settings** 클릭
   - Python version: 3.12 (기본값 그대로)
   - Secrets 칸에 붙여넣기 (`.streamlit/secrets.toml.example` 참고, 값은 내 것으로):
     ```
     OPENROUTER_API_KEY = "sk-or-v1-내키"
     LLM_MODEL = "openai/gpt-4o-mini"
     AGENT_TODAY = "2026-10-30"
     APP_PASSWORD = "내가정한비밀번호"
     MAX_QUESTIONS = "20"
     ```
   - **Save**
5. **Deploy** → 화면에 굽는 중(🧁) 애니메이션 → 2~5분 뒤 내 앱이 열림

✅ 확인: 휴대폰으로 링크 접속 → 비밀번호 입력 → "오늘 일정 요약" 버튼 동작

## STEP 5. 고치고 다시 배포하기 (Claude Code, 5분)
```
my_app.py 사이드바 제목을 "그린팜 업무 비서"로 바꾸고, 로컬에서 실행 확인한 다음
"사이드바 제목 변경" 메시지로 커밋해서 push 해줘.
```
✅ 확인: 1~3분 뒤 배포된 앱을 새로고침하면 제목이 바뀌어 있음 → **"push = 배포"**

## STEP 6. 비용·보안 안전장치 (5분, 꼭!)
| 할 일 | 어디서 | 이유 |
|---|---|---|
| 배포 전용 API 키를 새로 만들고 **Credit limit**(예: $2) 지정 | openrouter.ai/keys | 링크가 퍼져도 최대 비용이 정해짐 |
| APP_PASSWORD 설정 | Streamlit Secrets | 아무나 내 키로 AI를 쓰지 못하게 |
| MAX_QUESTIONS 설정 | Streamlit Secrets | 한 사람이 과도하게 쓰는 것 방지 |
| 강의 후 앱 삭제 또는 키 비활성화 | share.streamlit.io / openrouter.ai | 방치된 앱이 비용을 만들지 않게 |

## 🛠 막혔을 때
| 증상 | 확인할 것 |
|---|---|
| "Error installing requirements" | Manage app → 로그 확인. requirements.txt 패키지 이름 오타 |
| `ModuleNotFoundError: No module named 'config'` | sys.path 에 solution 폴더를 추가했는지 |
| `.env 파일에 OPENROUTER_API_KEY 를 넣어주세요` | Secrets 를 저장했는지, 키 이름 철자 |
| 업무폴더 파일이 0개 | GitHub 에 업무폴더가 올라갔는지 |
| 앱이 "Zzzz" 상태 | 12시간 미사용으로 잠든 것 → 깨우기 버튼 |
| push 가 거절됨 (rejected) | GitHub 저장소를 README 포함으로 만든 경우 → Claude Code 에 "pull 후 다시 push" 요청 |

```
배포된 앱에서 아래 에러가 나. Streamlit Cloud 로그 내용이야. 원인과, 내 PC에서 고쳐서 다시 push 하는 방법을 알려줘.
(Manage app → 로그 내용 붙여넣기)
```
