# 1교시 — 내 파일을 읽는 AI 만들기

목표: `업무폴더` 의 모든 파일을 읽어서 질문에 답하는 터미널 챗봇
정답 코드: `solution/config.py`, `llm.py`, `file_loader.py`, `step1_file_reader.py`

---

## 프롬프트 1-1. 프로젝트 파악시키기
```
이 폴더의 CLAUDE.md 와 업무폴더 구조를 먼저 읽어줘.
그리고 업무폴더에 어떤 종류의 파일이 몇 개씩 있는지, 파일 이름에 어떤 규칙이 있는지 표로 정리해줘.
아직 코드는 만들지 마.
```
✅ 확인: 일정 11개 / 회의록 5개 / 보고서 4개 / 미분류 1개, 날짜 규칙 3종류를 찾아내는지

## 프롬프트 1-2. LLM 연결 모듈 만들기
```
my_agent/ 폴더에 config.py 와 llm.py 를 만들어줘.

- config.py: .env 에서 OPENROUTER_API_KEY, LLM_MODEL(기본값 openai/gpt-4o-mini),
  WORK_DIR(기본값 ./업무폴더), AGENT_TODAY 를 읽는다. today() 함수는 AGENT_TODAY 가 있으면 그 날짜를,
  없으면 실제 오늘 날짜를 돌려준다.
- llm.py: openai 패키지로 OpenRouter(base_url=https://openrouter.ai/api/v1)에 연결하고,
  ask(system, user) 함수 하나로 답변 문자열을 돌려준다. 키가 없으면 친절한 한국어 에러를 낸다.

마지막에 llm.ask("한 단어로 답해", "안녕?") 을 실행해서 연결을 테스트해줘.
```
✅ 확인: 터미널에 짧은 인사말이 출력되면 성공

## 프롬프트 1-3. 파일 읽기 모듈 만들기
```
my_agent/file_loader.py 를 만들어줘.

- list_files(): 업무폴더 아래 모든 하위 폴더에서 .md .txt .csv .docx 파일을 찾는다.
  각 파일의 경로와 '카테고리'(바로 위 폴더 이름: 일정/회의록/보고서/미분류)를 함께 돌려준다.
- read_text(path): 확장자별로 텍스트를 읽는다. docx 는 python-docx 로 문단+표를 읽고,
  csv 는 'a | b | c' 형태의 줄로 바꾼다. 6000자가 넘으면 잘라낸다.
- build_context(files): 파일마다 '### [파일: 상대경로]' 머리표를 붙여 하나의 문자열로 합친다.
  전체 40000자를 넘으면 나머지는 생략 표시.

다 만들면 docx 파일 하나를 읽어서 앞부분 10줄만 보여줘.
```
✅ 확인: `고객사미팅_해담식품.docx` 내용(번들 19,900원 등)이 텍스트로 보이는지

## 프롬프트 1-4. 질문-답변 챗봇 완성
```
my_agent/step1_file_reader.py 를 만들어줘.

1. 실행하면 업무폴더 파일 목록과 개수를 출력한다.
2. 모든 파일 내용을 build_context 로 합친다.
3. '질문>' 입력을 반복해서 받고 q 를 누르면 종료한다.
4. 아래 시스템 프롬프트로 llm.ask 를 호출해 답한다.

[시스템 프롬프트]
너는 사용자의 업무 폴더 문서를 읽고 질문에 답하는 업무 비서다.
1. 반드시 [업무 문서]에 있는 내용만 근거로 답한다. 없으면 "문서에서 찾을 수 없습니다"라고 말한다.
2. 질문의 표현이 문서와 조금 달라도 같은 대상이면 찾아서 답한다. (예: '네이버 검색광고' = 표의 '네이버 검색')
   표 안의 숫자도 근거로 사용한다.
3. 답변 끝에 근거 파일명을 '출처:'로 적는다.
4. 한국어로, 핵심부터 짧게 답한다.
```

## 🧪 테스트 질문 (1교시)
| 질문 | 기대 답 |
|---|---|
| 해담식품이랑 번들 가격 얼마로 했어? | 19,900원 (18% 할인), 출처 docx |
| 콤부차 캠페인 슬로건이 뭐야? | "하루 한 병, 장까지 그린하게" |
| 9월 네이버 검색광고 ROAS는? | 520% |
| 우리 회사 사장님 이름이 뭐야? | 문서에서 찾을 수 없습니다 (환각 방지 확인) |
| 오늘이 몇 월 며칠 무슨 요일이야? | 문서에 오늘 날짜가 없어 모르거나 추측함 → **2교시로 연결되는 문제 제기** (step1은 대화 기록이 없어 후속 질문은 앞 답을 기억 못 함) |

## 💬 강사 포인트
- **환각 방지 규칙의 부작용**: "문서에 있는 것만"을 너무 엄격히 지시하면, 표에 '네이버 검색'으로 적힌 값을
  '네이버 검색광고'로 물었을 때 "찾을 수 없습니다"라고 답하기도 합니다. 규칙 2를 빼고/넣고 비교하는 시연 추천.
- "오늘 일정"을 물어보면 AI는 오늘이 며칠인지 모르고, 모든 날의 일정이 섞여서 헷갈려 합니다.
  → "AI에게 **필요한 파일만 골라서** 주는 것"이 2교시의 주제.
- 파일이 많아지면 `build_context` 가 40000자에서 잘림 = 비용과 정확도의 문제도 같이 언급.
