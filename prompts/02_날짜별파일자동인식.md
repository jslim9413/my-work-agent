# 2교시 — 요일·날짜별 파일 자동 인식

목표: "어제 회의록", "지난주 수요일 일정"처럼 말하면 해당 날짜의 파일만 골라 읽기
정답 코드: `solution/date_utils.py`, `finder.py`, `step2_date_finder.py`, `tests/test_date_utils.py`

핵심 아이디어 (화이트보드에 그리기)
```
질문 속 날짜 표현  ──▶  기간(start~end)  ─┐
                                          ├─▶ 두 기간이 겹치는 파일만 선택 ─▶ LLM
파일 이름 속 날짜  ──▶  기간(start~end)  ─┘
```

---

## 프롬프트 2-1. 파일 이름에서 날짜 읽기
```
my_agent/date_utils.py 에 file_date_range(filename) 함수를 만들어줘.
파일명 맨 앞의 날짜 규칙을 해석해서 (시작일, 종료일)을 돌려준다.
- 2026-10-28_마케팅회의.md → (2026-10-28, 2026-10-28)
- 2026-09_월간마케팅보고서.md → (2026-09-01, 2026-09-30)
- 2026-Q3_분기실적보고서.md → (2026-07-01, 2026-09-30)
- 날짜가 없으면 None
정규식은 주석으로 무슨 뜻인지 한국어로 설명해줘. 업무폴더 전체 파일에 돌려서 결과 표를 보여줘.
```

## 프롬프트 2-2. 질문 속 날짜 표현 해석 ★핵심
```
date_utils.py 에 parse_date_expression(text, today) 함수를 추가해줘.
질문 문장에서 날짜 표현을 찾아 DateRange(start, end, label) 로 돌려주고, 없으면 None.
띄어쓰기는 무시한다 ('지난 주' = '지난주').

지원할 표현 (위에 있을수록 먼저 검사):
1. 2026-10-28, 2026.10.28 / 10월 28일, 10/28
2. (지난주|이번주|다음주)? + 월~일요일  → 그 주의 해당 요일. 주 표현이 없으면 이번 주.
3. 그저께, 그제, 어제, 오늘, 내일, 모레 / N일 전 / 최근 N일
4. 지난주, 이번 주, 다음 주 → 월요일~일요일
5. 지난달, 이번 달, N월 / N분기, Q3

그리고 tests/test_date_utils.py 를 실행해서 전부 통과할 때까지 고쳐줘. 테스트 파일은 수정하지 마.
```
✅ 확인: `python -m pytest tests/test_date_utils.py -q` → 모두 passed

> 💡 강사 포인트: "왜 LLM한테 날짜 계산을 안 시키나요?"
> LLM은 '오늘'을 모르고, 요일 계산을 종종 틀립니다. **정확해야 하는 일은 코드로, 애매한 일은 AI로.**
> 실제로 LLM에게 "2026-10-30 기준 지난주 수요일은?"을 5번 물어보는 시연을 하면 효과적입니다.

## 프롬프트 2-3. 문서 종류 추정 + 파일 찾기
```
1) date_utils.py 에 guess_category(text) 를 추가해줘. 질문에 들어간 단어로 일정/회의록/보고서 중
   무엇을 원하는지 추정한다. (일정: 일정·스케줄·약속 / 회의록: 회의·미팅·액션·할일·담당 /
   보고서: 보고서·실적·성과·매출·광고비·전환율·ROAS) 해당 없으면 None.
2) my_agent/finder.py 에 find_files(start, end, category) 를 만들어줘.
   파일명 날짜가 없으면 파일 수정일을 날짜로 쓰고, 질문 기간과 파일 기간이 '겹치는' 파일만 돌려준다.
```

## 프롬프트 2-4. 날짜 인식 챗봇 완성
```
my_agent/step2_date_finder.py 를 만들어줘. step1 과 같은 대화형이지만:
1. 질문에서 날짜 범위와 문서 종류를 해석하고, 해석 결과와 선택된 파일 목록을 먼저 화면에 보여준다.
2. 선택된 파일만 LLM에게 전달한다. 0개면 LLM을 호출하지 않고 안내 문구를 출력한다.
3. 시스템 프롬프트 첫 줄에 "오늘은 2026-10-30 (금요일) 이다" 처럼 오늘 날짜와 요일을 넣는다.
```
