# 4교시 — 웹 화면 통합 · 미션 · 발표

목표: 3교시 Agent를 웹 화면(Streamlit)으로 감싸고, 미션 질문으로 내 Agent를 검증
정답 코드: `solution/step4_app.py` → 실행: `streamlit run solution/step4_app.py`

---

## 프롬프트 4-1. 웹 화면 만들기
```
my_agent/step4_app.py 를 streamlit 으로 만들어줘. step3_agent.py 의 Agent 를 재사용한다.
- 가운데: 채팅 화면 (st.chat_message / st.chat_input), 대화 기록 유지(session_state)
- 답변 위에 접을 수 있는 '🔧 Agent가 사용한 도구' 영역
- 왼쪽 사이드바: 오늘 날짜/모델명 표시, 빠른 실행 버튼 3개
  (📅 오늘 일정 요약, 📅 이번 주 일정 요약, ✅ 이번 주 액션아이템), 업무폴더 파일 목록, 대화 초기화
- 액션아이템을 실행하면 아래에 CSV 다운로드 버튼(utf-8-sig)
실행 명령어도 알려줘.
```

## 프롬프트 4-2. 내 스타일로 꾸미기 (선택)
```
step4_app.py 의 디자인을 바꿔줘. 우리 팀 이름은 '그린팜 마케팅팀'이고 메인 색은 초록색이야.
상단에 오늘 일정 개수, 이번 주 회의 수, 미분류 파일 수를 숫자 카드(st.metric) 3개로 보여줘.
```

## 프롬프트 4-3. 내 실제 업무폴더 연결 (선택, 개인정보 주의)
```
.env 의 WORK_DIR 을 내 실제 폴더로 바꿨어. 파일명 날짜 규칙을 안 지킨 파일이 몇 개인지,
어떤 이름으로 바꾸면 좋을지 '바꿀 이름 제안 표'만 만들어줘. 실제 파일 이름은 절대 바꾸지 마.
```

## 🏁 미션 (20분, 2인 1조)
`질문테스트시트.md` 의 20문항을 내 Agent에 넣고 O/X 채점 → 가장 많이 맞힌 조가 발표

추가 미션 (빨리 끝낸 사람)
1. **금요일 자동 주간보고**: "이번 주 일정+회의록+액션아이템을 묶어 주간 업무 보고서 초안을 써줘" 기능 추가
2. **미분류 정리 도우미**: 미분류 폴더 파일을 읽고 어느 폴더/어떤 파일명이 맞는지 제안
3. **아침 브리핑**: 실행하면 질문 없이 "오늘 일정 + 오늘 마감 할 일 + 어제 회의 핵심"을 바로 보여주기

## 🎤 발표 템플릿 (조별 2분)
1. 우리 Agent가 가장 잘한 질문 1개 (화면 시연)
2. 틀린 질문 1개와 원인 (날짜 해석? 파일 선택? 프롬프트?)
3. 내 실제 업무에 붙인다면 어떤 폴더에, 무슨 질문을 매일 할지
