# 프롬프트 사용법

이 폴더의 프롬프트는 **AI 코딩 도구(Claude Code, Cursor 등)에 그대로 붙여넣는 작업 지시서**입니다.

## 순서
1. 키트 폴더(`ai-file-agent-kit`)를 열고 터미널에서 `claude` 실행 (Cursor라면 채팅창 열기)
2. 교시별 파일의 **프롬프트 1 → 2 → 3** 순서로 하나씩 붙여넣기
3. AI가 만든 코드를 실행 → 결과 확인 → 이상하면 "🛠 막혔을 때" 프롬프트 사용
4. 시간이 부족하면 `solution/` 의 같은 단계 파일을 실행해서 따라잡기

## 좋은 지시의 5요소 (모든 프롬프트가 이 구조)
| 요소 | 예시 |
|---|---|
| 목표 | 업무폴더 파일을 읽고 답하는 프로그램을 만들어줘 |
| 입력 | `업무폴더/` 아래 .md .txt .csv .docx |
| 출력 | 터미널 대화형, 답변 끝에 출처 파일명 |
| 제약 | 파일 150줄 이내, 한국어 주석, CLAUDE.md 규칙 준수 |
| 확인 방법 | "오늘 일정 알려줘"를 넣으면 10/30 일정이 나와야 함 |

## 공통 꿀팁
- 한 번에 다 시키지 말고 **한 단계씩**. 실행 확인 후 다음 프롬프트.
- 에러가 나면 에러 메시지 **전체를 복사**해서 붙여넣기만 해도 대부분 해결됩니다.
- "코드 설명해줘"보다 "이 코드가 하는 일을 비전공자에게 3줄로 설명해줘"가 훨씬 좋습니다.
